The following contents are included in this repository:

**VOSARA Reefs:** Download this html to view oyster reefs in Virginia's Chesapeake Bay that are monitored by the Molluscan Ecology Patent Tong Survey, organized yearly by a collaboration between the Virginia Institute of Marine Science (VIMS) and the Virginia Marine Resource Commission (VMRC). Reefs that are included in the Gaussian Mixture Modeling (GMM) cohort analysis project are purple, reefs that are excluded are orange. Included reefs have at least eight consecutive years of at least 300 total oysters (spat or live) sampled.

**GMM Map:** Download the zipped html to view GMM model output for the 64 included reefs in the GMM cohort analysis project. A detailed README document is included as a popup. The algorithm to track the estimated Gaussian distributions over time is described in Griffin et al. (in progress). Please allow time for the map to load in your browser.
