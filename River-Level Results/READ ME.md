This folder contains subfolders for each of the 7 River strata included in this analysis: Chesapeake Bay Mainstem, James River, Great Wicomico River, Piankatank River, Rappahannock River, Tangier & Pocomoke Sounds, and York River & Mobjack Bay. 

Each subfolder will contain the following PDFs or PNGs:

**Cohort Figs:** Temporal visualization of estimated cohorts $\hat{c}^{(k)}\_{Rrt}$ in each R stratum. Points represent $\hat{\mu}^{(k)}\_{Rrt}$ and error bars represent $\hat\sigma\_{Rrt}^{(k)}$ of the estimated components. A green panel background represents $n\_{Rrt}^{(live)} > 250$, while a pink panel background represents $n\_{Rrt}^{(live)} \leq 250$. A black asterisk (∗) represents $n\_{Rrt}^{(spat)} < 50$. The number next to each point represents $\hat{a}^{(k)}\_{Rrt}$. The orange dotted line represents the market size in Virginia (76 mm). Each page in the pdf corresponds to a different analyzed reef.

**Cohort Overlap:** Estimated distributions for cohorts in each R stratum. Each pane refers to a different identified cohort ($\hat{c}^{(k)}\_{Rrt}$). Note that the mixture weights of each cohort ($\hat{\pi}^{(k)}\_{Rrt}$) do not sum to one because each component $k$ is linked over time, while the GMM (with its mixture weights) was estimated yearly. Each page in the pdf corresponds to a different analyzed reef.

**Age Truncation:** Age structure over time in each analyzed reef from in each R stratum. The red line represents the midpoint in the 21-year time series (2013). Green dots represent estimated ages of one to three and orange dots four and older. 

**Shell Size Shrinkage Curves:** SL distributions of each estimated age group, colored by decade, for each river stratum. The facet labels represent each $\hat{a}^{(k)}\_{Rrt}$. Each page in the pdf corresponds to a different analyzed reef.
